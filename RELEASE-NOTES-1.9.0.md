# DEEP-ECHO Mobile 1.9.0

DEEP-ECHO Mobile 1.9.0 is the first Android release in the GitHub auto-update chain.

## Highlights
- In-app GitHub Release update checking with an Update Available dialog.
- Signed APK download with optional SHA-256 verification before installation.
- Queue / Up Next controls and Smart Autoplay improvements.
- Expanded About Artist experience with songs, playlists/albums, and related artists.
- Smarter Home recommendations.
- Auto Theme With Song, suggested themes, theme-aware live visuals, and vertical volume control.
- Improved synced lyrics, Word-by-Word behavior, Romanized-only mode, SYNC recovery, and Floating Lyrics.
- Downloads, playback, likes/history, playlists, search, themes, and developer information preserved.

## Update compatibility
Package: `com.deepecho.mobile`

Release tag: `v1.9.0`

GitHub updater repository: `windowsdaiyu-cyber/DeepEcho-Android`

The permanent Android signing key used for the tested v1.9.0 APK must be reused for every future APK. Android will still show its normal system install/update confirmation.
