DEEP-ECHO ANDROID — ONE-SHOT GITHUB FIX

This folder is a complete Android repository replacement.

1. Open your GitHub repository: DeepEcho-Android.
2. Code -> Add file -> Upload files.
3. Open THIS extracted folder in Windows Explorer.
4. Select EVERYTHING INSIDE it (including .github, app, bridge, gradle, ci and root files).
5. Drag the selected items onto GitHub upload.
6. Commit directly to main.
7. Open Actions. The DeepEcho Android APK workflow starts automatically.
8. After a green run, open the run and download artifact: DeepEcho-Android-v0.1.0-alpha-APK.

DO NOT upload this to the Windows/PC DeepEcho repository.
