# DEEP-ECHO Mobile 1.10.2

DEEP-ECHO Mobile 1.10.2 is the next Android update in the existing GitHub auto-update chain.

## Highlights
- Reworked Live/Ambient visuals with brighter theme-aware particles while protecting UI readability.
- Added an Ambient Mode control beside the loop/repeat control and kept theme-specific ambient behavior.
- Added Listening Stats with listening time, plays, top songs, top artists, and recent summaries.
- Expanded Search with Top Result plus Songs, Videos, Albums, Artists, suggestions, and result-type labels.
- Improved Home scrolling performance and reduced unnecessary rendering/warm-up work.
- Strengthened lyrics lookup/matching, sync fallbacks, Word-by-Word behavior, and Romanized lyrics support.
- Added a dedicated Floating Lyrics ON/OFF control.
- Added theme-aware Floating Lyrics bounce and shine.
- Removed the reactive graph from the in-app Lyrics screen.
- Redesigned the Floating Lyrics visualizer as a transparent PC-style waveform with a subtle baseline/glow and audio-reactive motion.
- Added theme-specific Like/Download celebration animations.
- Preserved the stable playback/download/update chain and Android package identity.

## Update compatibility
Package: `com.deepecho.mobile`

Release tag: `v1.10.2`

GitHub updater repository: `windowsdaiyu-cyber/DeepEcho-Android`

This APK must be signed with the same permanent Android signing key used for v1.9.0 so it installs as an update over existing DEEP-ECHO Mobile installations.
